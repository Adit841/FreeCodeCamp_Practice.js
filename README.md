## 📂 Repository Structure

Each problem has its own folder so that the problem statement and the solution stay organized.

```
project-name/
│
├── README.md
│
└── questions/
    │
    ├── question-name/
    │   ├── solution.js
    │   └── question.txt
    │
    ├── another-question/
    │   ├── solution.js
    │   └── question.txt
```

### Explanation

* **solution.js** → My JavaScript solution to the problem
* **question.txt** → The original problem statement from the lab

This structure makes it easier to understand what the problem was and how it was solved.
